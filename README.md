# 角色卡与世界书联动删除（SillyTavern Extension）

删除角色卡后，询问是否同时清理其绑定的世界书。支持单个与批量删除，**只有确认后才删除世界书**。

当前版本：**v1.3.0**（已在实际 SillyTavern 环境中测试了单删、批量删除及保留功能）。

## 功能

- 监听角色卡删除，等角色卡删除流程结束，再统一询问是否删除关联世界书。
- 显示候选世界书名称；可选择保留或永久删除。
- 默认只考虑角色的主要世界书；可在扩展设置中主动开启附加世界书。
- 对检测到由其他角色、全局配置、用户人设或当前聊天引用的世界书采取保留策略。
- 支持待处理列表与不删除数据的弹窗测试。
- 无需「酒馆助手」扩展，基于 SillyTavern 前端接口实现。

> **注意：** 世界书删除不可撤销。插件无法遍历所有历史聊天的独立世界书绑定；重要资料请先备份。不建议同时启用其他执行相同删除功能的扩展，以免冲突。

## 安装

**通过 GitHub URL 安装（仓库上传后）：** 在 SillyTavern 的扩展管理器中选择安装扩展，粘贴此仓库的 HTTPS 地址，安装成功后刷新页面。

**手动安装：** 将包含 `manifest.json`、`index.js`、`style.css` 的整个插件目录放入 SillyTavern 对应的第三方扩展目录，然后刷新页面。

请避免本地与全局扩展目录同时保留两份本插件，也不要在更新时将新文件夹嵌套到旧文件夹内。

## 使用

1. 在扩展设置中找到「角色卡与世界书联动删除 v1.3.0」。
2. 可先点击「测试 v1.3 弹窗（不删除数据）」检查确认窗口。
3. 正常删除角色卡；等原生删除流程结束后，插件将列出可以确认处理的世界书。
4. 选择「保留世界书」或「确认永久删除」。共享或已不存在的世界书不会参与删除操作。

## 更新

仓库升级后，可使用 SillyTavern 扩展管理器的更新功能检查并更新扩展；安装前请备份。`manifest.json` 中的 `auto_update` 当前为 `false`，不代表无法手动更新。

## 版本说明

- 保留未确认删除的待处理世界书，避免自动误删。
